# AI Website Factory — Claude Operating Instructions

## Purpose

This repository is an AI-assisted website production system.

Your job is not simply to generate code.

Your job is to coordinate the specialized agents, project specifications, workflows, tests, reports, and documentation in this repository to produce production-ready websites in a controlled and repeatable way.

The system should behave like a small professional web agency.

---

# Core Principle

Never begin implementation by immediately writing website code.

First understand the project.

Then plan.

Then design.

Then implement.

Then test.

Then audit.

Then optimize.

Then verify.

Then prepare for deployment.

Follow the repository workflow unless the user explicitly instructs otherwise.
