# Website Type Starting Point — Contractor / Professional Services

This is a starting point for the Intake stage, not a substitute for it. Confirm every item below with the owner before treating it as approved; this file follows the same evidence-based approach used on other factory projects — do not publish licensing, insurance, or credential claims that have not been verified.

## Suggested pages

- Home
- Services
- About
- Service Area
- Contact / Request a Quote
- FAQ

## Suggested features

- Quote/consultation request (start as a non-sending preview unless a real submission workflow is explicitly approved)
- Service area description (confirm exact coverage — do not imply broader coverage than verified)
- License, insurance, and certification display (only with documented evidence)
- Before/after gallery, only with rights-cleared photography and owner permission per project

## Common owner inputs still needed

- Legal business name and entity type
- Exact services offered and explicitly excluded
- License numbers, insurance carrier/type, and any certifications, with evidence
- Service area boundaries and any travel limits
- Pricing approach (published rates, "contact for quote," or a hybrid)
- Response-time expectations

## Things to avoid without verified evidence

- "Licensed and insured" or similar claims without a license number/insurance confirmation on file
- Implying availability or service area broader than confirmed
- Before/after images without the client's and owner's permission
