# Website Type Starting Point — Restaurant

This is a starting point for the Intake stage, not a substitute for it. Confirm every item below with the owner before treating it as approved; do not publish menu items, prices, hours, or claims that have not been verified.

## Suggested pages

- Home
- Menu
- About
- Hours & Location
- Reservations / Contact
- Gallery (only with rights-cleared photography)

## Suggested features

- Reservation request (start as a non-sending preview unless a real booking system is explicitly approved)
- Menu display (confirm whether prices are approved for publication)
- Hours, location, and contact details
- Map/directions link (only after the address is approved for public display)

## Common owner inputs still needed

- Legal business name and entity type
- Exact hours, including holiday variations
- Menu items, prices, and dietary/allergen information
- Reservation or waitlist process
- Delivery/takeout partners, if any
- Health/safety certifications, if the owner wants them displayed (verify before publishing)

## Things to avoid without verified evidence

- "Best," "award-winning," "#1," or similar superlative claims
- Star ratings or review excerpts without a linked, verifiable source
- Menu prices that are not current
