# Website Type Starting Point — Portfolio

This is a starting point for the Intake stage, not a substitute for it. Confirm every item below with the owner before treating it as approved.

## Suggested pages

- Home
- Work / Projects (gallery or case-study format)
- About
- Contact

## Suggested features

- Project gallery with rights-cleared images only
- Case study / project detail pages, if the owner has enough material for them
- Contact form (start as a non-sending preview unless a real submission workflow is explicitly approved)
- Resume/CV download, if the owner wants one included

## Common owner inputs still needed

- Which projects to feature and in what order
- Image/media rights for every asset used
- Client names — confirm each one is approved for public display before including it
- Preferred contact method and expected response time

## Things to avoid without verified evidence

- Client logos or testimonials without explicit permission
- Project outcomes or metrics ("increased revenue by X%") without the owner's confirmation
- Implying an ongoing client relationship that has ended, unless the owner confirms it's still current
